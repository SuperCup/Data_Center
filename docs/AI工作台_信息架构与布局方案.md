## 3. 布局结构（Codex / WorkBuddy 风格）

### 3.1 全局壳（所有页面共用）

```
┌────────┬──────────────────────────────────────────────┐
│        │  Top Bar：品牌名 · 模式指示 · 用户            │
│  Icon  ├──────────────┬───────────────────────────────┤
│  Rail  │              │                               │
│        │  Left Panel  │        Main Canvas            │
│ 导航   │  （按场景变） │     （对话 / 看板 / 管理页）    │
│        │              │                               │
│ AI工作台│              ├───────────────────────────────┤
│ 融合首页│              │  Right Panel（可折叠）         │
│ 到店…  │              │  上下文 / 产出物 / 记忆片段     │
│ 即时…  │              │                               │
│ 物码…  │              │                               │
│ 知识库 │              │                               │
│ 记忆   │              │                               │
│ 产出物 │              │                               │
└────────┴──────────────┴───────────────────────────────┘
```

- **最左 Icon Rail（~56px）**：一级导航，参考 WorkBuddy / Codex。
- **Left Panel（~260px，可折叠）**：随一级导航切换内容（会话列表 / 看板子菜单 / 知识库目录等）。
- **Main Canvas**：主工作区。
- **Right Panel（~300px，可折叠）**：产出物、引用看板片段、记忆命中、建议卡片。

### 3.2 融合首页（默认首屏）

一屏完成「看见生意 + 发起 AI + 进入固定看板」：

1. 顶部：品牌经营一句话摘要 + 3～4 个核心 KPI
2. 中部：AI 能力三卡片（查数 / 经营分析 / 商机探索）→ 点击进入对应预设会话
3. 下部左：最近会话列表
4. 下部右：最近产出物
5. 底部或侧栏：到店 / 即时零售 / 物码 固定看板入口

### 3.3 AI 工作区（对话模式）

Agent 核心能力（六项）：

1. **数据查询** — 自然语言查看板指标  
2. **经营诊断** — 异常与根因定位  
3. **数据分析** — 对比 / 趋势 / 结构 / 机制效果  
4. **行动建议** — 可落地 P0/P1 动作清单  
5. **商机探索** — 渠道 × 品类机会矩阵  
6. **报告生成** — 汇总为经营报告产出物  

### 3.4 固定看板模式 + AI 侧栏

进入到店 / 即时零售 / 物码任一看板时：

- Left Panel 切为该业务子菜单（活动管理、销售分析等，原型用占位页即可）
- Main 展示看板内容（可用简化图表 / 表格 mock）
- 右下角「问 AI」按钮 → 展开 Right Panel 或浮层侧栏
- 侧栏自动带上「当前看板上下文」（页面名、筛选条件、可见指标）

### 3.5 管理页

| 模块 | 主区能力 | 右栏 |
|------|----------|------|
| 品牌知识库 | 文档/口径/规则列表；上传（模拟）；预览；启用/停用 | 引用次数、关联会话 |
| 个人行为记忆 | 偏好、常看指标、历史提问、浏览轨迹；可编辑/删除/置顶 | 记忆如何影响回复的说明 |
| 产出物中心 | 报告 / 图表卡 / 建议卡 / 导出文件；筛选、预览、下载（模拟） | 来源会话、关联看板 |
| 会话管理 | 与 AI 工作区 Left 同源；支持重命名、分组、删除、置顶 | — |

与「文件交付」关系：**并存**。产出物偏 AI 生成物；文件交付偏线下/运营交付文件。导航两者都保留。

## 5. 视觉方向（避免通用 AI 紫风）

- 基调：深色侧栏 + 浅色工作区（偏专业数据产品，非消费级紫渐变）
- 主色：青绿 / 青绿偏蓝（数据可信感），点缀琥珀用于「建议 / 商机」
- 字体：标题用有辨识度的无衬线展示体（如 Outfit / DM Sans），正文用 Source Han / 系统中文回退
- 动效：侧栏展开、消息流出现、产出物卡片生成 — 2～3 处有意动效即可
