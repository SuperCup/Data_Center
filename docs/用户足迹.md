### 用户需求
版面需要增加 AI 元素：基于看板向 AI 查数、经营分析建议、商机探索；含会话管理、品牌知识库、个人行为记忆、产出物管理。参考 Codex / WorkBuddy，保留到店 / 即时零售 / 物码固定看板。

### 拍板结论
1. 先做过独立 HTML 原型，后改为**直接在 data-center React 项目调整**
2. 布局：看板与 AI **切换式**（非融合）
3. 会话记录：**侧栏常驻**（切换 AI 菜单不隐藏）
4. AI 深度：仅 UI + 模拟对话
5. Agent 六能力：数据查询、经营诊断、数据分析、行动建议、商机探索、报告生成
6. UI 需更精细，对齐现有 Ant Design 风格
